Internship project · GLPI, SNMP, Wazuh

Replacing Excel inventories with GLPI, and getting ready for Wazuh

Context

A document-management company tracked its computers and network devices in Excel files and on paper. Finding a device was slow, nobody knew which software was installed where, and security incidents were only noticed after the fact.

What I built

  1. Prepared a Windows machine with WampServer, which provides Apache, PHP and MySQL.
  2. Installed GLPI with its web installer, changed every default password and deleted the install folder.
  3. Modeled the company in GLPI: departments, buildings, offices and hardware categories.
  4. Enabled SNMP on printers, scanners and other devices, then created a network discovery task.
  5. Installed the GLPI agent on Windows workstations so hardware and software details report automatically.
  6. Installed Wazuh agents on critical workstations, ready to send logs to a Wazuh manager.

Problems and fixes

What went wrong

Agent deployment through Active Directory didn’t work. Internal constraints blocked it.

What I did

Installed the agent on each workstation by hand. It took longer but gave full coverage without touching the domain setup.

What went wrong

Only one machine was powerful enough, and it was already in production. GLPI ran there, leaving no room for a Wazuh manager.

What I did

Installed the agents first, so monitoring can start as soon as a server is available.

What went wrong

Network devices stayed invisible until SNMP was configured on them.

What I did

Enabled and checked SNMP device by device, then ran the discovery task again.

Result

Printers, scanners, switches, Wi-Fi access points and NAS devices were discovered automatically, and workstations report their own inventory. The old Excel files are no longer needed.

Next steps

Add a dedicated server for the Wazuh manager, connect GLPI and Wazuh through the API so alerts create tickets, and back up the GLPI database regularly.

What I learned

Automation plans often meet real-world limits. A manual fallback, and preparing the next step early, kept the project moving.
